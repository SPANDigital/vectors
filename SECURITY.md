# Security Policy

## Supported Versions

The following versions of the vectors library are currently supported with security updates:

| Version   | Supported          |
| --------- | ------------------ |
| 1.x.x     | :white_check_mark: |
| 0.2.x     | :x:                |
| < 0.2.0   | :x:                |

We provide security updates for the latest major version (1.x.x). Previous 0.x versions are no longer supported following the v1.0.0 stable release.

## Reporting a Vulnerability

If you discover a security vulnerability in the vectors library, please report it responsibly:

1. **Do NOT** open a public GitHub issue for security vulnerabilities
2. Email [richard.wooding@spandigital.com](mailto:richard.wooding@spandigital.com) with:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if available)

### What to Expect

- **Initial Response**: Within 48 hours
- **Status Update**: Within 5 business days
- **Resolution Timeline**: Depends on severity
  - Critical: Within 7 days
  - High: Within 14 days
  - Medium/Low: Within 30 days

We appreciate your responsible disclosure and will credit you in the security advisory (unless you prefer to remain anonymous).
